# SoleNexa — Windows downloads

**Install SoleNexa (first time):** open the [latest release](https://github.com/qamaruzaman131/SoleNexa-releases/releases/latest) and download **SoleNexa-Setup-x.x.x.exe**, then run it.

- Already have SoleNexa? Install over it — your factory data stays where it is.
- After that, SoleNexa updates itself: new versions download in the background and install when you close the app (or click **Restart** in the top bar).
- Windows may say "Unknown publisher" because the installer is not code-signed yet: choose **More info → Run anyway**.

This repository only holds the installers. Software by IQ Links.
